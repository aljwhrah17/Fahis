# فاحص 🏦🔍

An AI-powered smart platform designed for early and precise detection of money laundering, bribery, and banking crimes to ensure full regulatory compliance.

## 📌 About the Project
فاحص was developed for the Amd Hackathon (Financial Regulations track) in collaboration with Alinma Bank and Tuwaiq Academy. 
The platform addresses vulnerabilities in traditional banking systems by tracking complex relationships, looping transactions, and hidden networks to prevent financial crimes proactively.

## 🛠️ Tech Stack & Architecture
* AI/ML: Graph Neural Networks (GNN) for relational analysis, Machine Learning for behavioral profiling.
* Explainability: Explainable AI (XAI) for generating transparent, automated compliance reports.
* Frontend/Backend: React, Vite, Python, and secure APIs.

## ⚙️ Key Capabilities
1. Complex Relationship Tracking: Uncovers indirect links, shell companies, and hidden beneficial ownerships.
2. False Positives Reduction: Advanced AI classification minimizes false alarms, reducing investigation time from hours to seconds.
3. Explainable AI (XAI) Dashboards: Provides clear, human-understandable justifications for suspicious activity alerts.
